# Personal data in the corpus

Who each field is about, how sensitive it is, and which fields the public
release drops (issue #142). Generated by `scripts/pii_inventory.py` from
`docs/personal-data.tsv`, measured over 113,073 records on 2026-09-08;
`tests/test_pii_inventory.py` fails when a record holds a path the table
does not. The terms under which any of it may be reused, and whom to write
to about a person's record, are in [DATA_TERMS.md](../DATA_TERMS.md).

## The four subjects

| subject | paths | who |
|---|---:|---|
| `candidate` | 769 | the candidate: what they declared about themselves |
| `family` | 41 | the candidate's spouse, partner, children or other family members |
| `third-party` | 115 | someone else named on the candidate's pages: a treasurer, an auditor, a donor, a counterparty, a trustee |
| `none` | 244 | not about a person: an election fact, an organisation, an identifier, a URL, a hash |

`records` below is the widest reach of any path in the group -- how many
records carry at least that field -- not a sum over paths.

declarations' spouse sections; third-party fields are the people a campaign
or a declaration has to name by law: treasurer, auditor, donors, counterparties.

## What the public release drops

`scripts/build_distribution.py --profile public` (the default) removes
these values from every record before it writes `vrk-corpus.sqlite`; the
`records` table and `reconstruct_record` then reproduce the record *without*
them. `--profile full` ships everything, for a mirror of the archive. None
of the dropped paths reaches `candidacies.csv.gz`, the coverage gate or the
dashboard's comparison rows, so the public profile costs nothing a consumer
of those can see. `MANIFEST.json` records the profile and how many values
were removed.

## What the derived layers surface

The release carries every record whole; what the candidacy table, the person
index and the dashboard lift *out* of the records is a narrower, deliberate
set (issue #162). Declared nationality (`ethnic` above, a special category
of personal data) is the candidacy table's `nationality` and the dashboard's
nationality facet, comparison row and summary section, folded from 117
spellings into 45 census groups by `scraper/shared/tautybe.py` -- the
corpus's one minority-representation series, 89,154 answers over 30 years.
The statutory declarations (`eligibility`: another citizenship, an oath to a
foreign state, military service, collaboration with foreign or Soviet
special services, a lost mandate) are concepts in `docs/concept-map.json`,
the table's `declarations_status` and `declarations_flagged`, and one
dashboard row that lists only the answers departing from the usual one.
Deliberately *not* surfaced: the spouse's and children's names are measured
by the fill gate and read by no column, row or index field, and the home
address is mapped nowhere -- VRK prints them for the voter reading one page,
not for a register.

## Portraits

Every portrait is stored once in the `photos` table under the sha256 of the
bytes VRK served, which is what the record's `photoMeta.sha256` names. In the
public profile the stored bytes are passed through
`scraper/shared/image_metadata.py` first: the Exif block (GPS position,
camera serial, `Artist`, `CameraOwnerName` -- 9,889 of the 27,493 sidecars
carry one, 1,215 with a GPS IFD), the XMP packet, the Photoshop/IPTC block
and JPEG comments are removed and the picture is copied through unchanged;
PNG text and Exif chunks likewise. `photos.stripped` says whether anything
was removed and `photos.stripped_sha256` hashes what is stored, so the
archive stays verifiable against the original hash and the release carries
the face and nothing else. The archive under `data/` is not touched.

## Regenerating

```bash
python scripts/pii_inventory.py          # measure data/, rewrite the table and this file
python scripts/pii_inventory.py --check  # exit 1 on a path the table lacks
```

A new path means a parser started emitting a field; add a rule to `RULES`
in the script -- whose data it is, how sensitive -- and regenerate. A path
that should not ship goes into `PUBLIC_PROFILE_DROPS` there, which is the
list the distribution builder reads.
