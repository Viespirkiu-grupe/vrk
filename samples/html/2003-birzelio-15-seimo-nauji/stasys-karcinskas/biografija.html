Stasys KARČINSKAS

Stasys KARČINSKAS
Liberalų demokratų partijos kandidatas į
Lietuvos Respublikos Seimo narius NEVĖŽIO
rinkimų apygardoje, Nr. 26

Stasys Karčinskas gimė 1959 m. kovo 20 d. Pasvalyje.
Nuo 1967 m. mokėsi Panevėžio 6-ojoje vidurinėje mokykloje (dabar - Gabijos vidurinė mokykla), kurią baigė 1977 m.
1977 m. įstojo į Vilniaus universiteto Matematikos fakultetą, kurį baigė 1984 m. Įgijo matematiko specialybę (specializacija - taikomoji matematika). Studijuodamas aktyviai dalyvavo visuomeninėje veikloje, buvo Universiteto dainų ir šokių ansamblio choro dalyvis.
Nuo 1984 m. pagal paskyrimą dirbo Panevėžio mėsos kombinato informaciniame skaičiavimo centre inžinieriumi matematiku, nuo 1990 m. - inžinieriumi programuotoju.
Nuo 1995 m. dirbo akcinėje bendrovėje "Tulpė" inžinieriumi programuotoju.
1996 m. laimėjo konkursą ir pradėjo dirbti Panevėžio miesto valstybinėje mokesčių inspekcijoje programuotoju.
1999 m. Panevėžio miesto valstybinę mokesčių inspekciją reorganizavus į Panevėžio apskrities valstybinę mokesčių inspekciją paskirtas Informacinių sistemų skyriaus viršininko pavaduotoju, 2001 m. - Informacinių sistemų ir analizės skyriaus viršininko pavaduotoju.
Nuolat kėlė kvalifikaciją. Turi 13 tarptautinių kursų baigimo sertifikatų:
1997 m. - 803 Administering Microsoft® Windows NTTM 4.0
Non-Procedural Programming With SQL and SQL*Plus(SQL)
Administer Oracle7 Workgroup Server(O7W);
1999 m. - Overview of Microsoft Exchange Server 5.5 (#1045)
Oracle8: Database Administration(O8A);
2000 m. - Enterprise DBA Part 1B: Backup and Recovery Workshop (DBA1B)
Supporting Microsoft Windows NT Server 4.0 Enterprise Technologies (#689)
1560 Updating Support Skils from Microsoft Windows NT 4.0 to Microsoft Windows 2000;
2001 m. - Enterprise DBA Part 3: Network Administration (DBA3);
2002 m. - WM-data: Computer Audit Education
Oracle iDS Reports: Build Internet Reports(RP6i);
2003 m. - Oracle9i Database Performance Tuning (9iPT)
European Computer Driving Licence (passed all 7 modules).
Nuo 2002 m. - Liberalų demokratų partijos narys. Dabar - Panevėžio miesto Liberalų demokratų partijos pirmininko pavaduotojas.
Domisi informacinių technologijų raida, informacinių technologijų galimybių praktiniu taikymu.
Pomėgiai - grožinė literatūra, poilsis gamtoje, kompiuteriniai žaidimai.
Moka rusų, anglų kalbas.
Žmona Aldona - akcinės bendrovės "Panevėžio pienas" kadrų inspektorė.
Turi dukteris Rasą ir Vaidą, kurios mokosi Panevėžio "Žemynos" vidurinėje mokykloje.
